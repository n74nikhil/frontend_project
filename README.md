# Netflix Clone

A responsive Netflix landing page clone built using HTML and CSS. This project recreates the look and feel of Netflix's homepage, including the hero section, feature highlights, FAQ section, and footer.

## Features

* Responsive design for desktop and mobile devices
* Netflix-inspired user interface
* Hero section with call-to-action
* Feature sections with images and videos
* Interactive FAQ section
* Clean and modern layout using Flexbox and CSS Grid

## Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries

## Project Structure

* `index.html` – Main webpage structure
* `netflix.css` – Styling and responsive design
* `bg.jpg` – Background image
* `logo.svg` – Netflix logo
* `favicon.ico` – Website favicon
